# AzureSky Quality Management System and Laboratory Documentation

This repository contains the AzureSky quality system documentation, laboratory procedures, validation records, and supporting assessment materials used to support compliant coal testing and analytical operations.

## Overview

The project brings together the core AzureSky QMS reference library and the total moisture test method documentation in one GitHub repository. It is intended to provide a structured, version-controlled source for:

- ISO/IEC 17025 quality management documentation
- laboratory procedures and controlled forms
- technical validation and uncertainty documentation
- sample preparation and testing process records
- internal assessor and operator guidance

## Repository structure

- `AZURESKY QMS/` — archived and current QMS source folder imported from the core AzureSky system
- `QMS-17025/` — ISO/IEC 17025 clause-based quality management files
- `Total-Moisture/` — total moisture SOP, training, and supporting documentation
- `CWP-001/` — operational and technical project documentation
- `AXIS/` — supporting analytical system or process documentation
- `PT_CRM_Customers/` — proficiency testing or customer-related quality records
- `README.md` — repository landing page

## Primary purpose

These documents support:

- structured laboratory operations
- method selection, validation, and verification
- equipment and calibration control
- sample handling and technical recordkeeping
- management review, internal quality, and customer-facing compliance

## Related standards and controls

The repository aligns with and references:

- ISO/IEC 17025:2017
- ISO 17034 and related quality documents
- ISO 589 and ISO 13909 as applicable to coal moisture testing
- AzureSky internal technical procedures and assessment materials

## Notes

This repository is designed as a controlled documentation set for laboratory quality and operational governance. It should be used alongside the organization’s formal document control and approval processes.

## Suggested usage

- Review the clause-based QMS folder for governance and management requirements.
- Use the Total-Moisture folder for method-specific sample preparation and moisture testing procedures.
- Reference the assessment and validation materials when training analysts or reviewing laboratory performance.
