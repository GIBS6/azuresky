# AzureSky Laboratory QMS and Total Moisture

This repository contains the AzureSky quality management system and laboratory moisture-testing documentation.

## Contents

- QMS-17025/ — ISO/IEC 17025 quality management documentation organized by clause
- Total-Moisture/ — total moisture procedure, assessments, guides, and supporting files

## Purpose

These documents support structured laboratory operations, validation, training, and quality compliance for coal testing and sample preparation.
