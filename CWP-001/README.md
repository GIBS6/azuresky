### 1. Project Charter & System Integration Philosophy

Project **CWP-001** is engineered as an **auditable, controlled technical extension of AzureSky (Pty) Ltd's existing laboratory operations**. Rather than designing a parallel or hypothetical greenfield laboratory, this repository establishes the precise technical, metrological, operational, and quality pathways required to extend AzureSky's current SANAS-accredited scope (Sample Preparation, Proximate Analysis, and Calorific Value) to include **Coal Washability Testing by Dense Medium Separation (Float & Sink)** and **Particle Size Distribution (PSD)**.

Every requirement in this project is anchored to:
1. **The authentic text of current international standards** (ISO 7936:2022, ISO 1953:2025, ISO 13909:2025, ISO 18283:2022).
2. **AzureSky's active ISO/IEC 17025:2017 Quality Management System** on drive `Z:`.
3. **The Mandatory Document Link & Traceability Rule**, providing exact file-level navigation across the complete evidence chain.

### 2. Document Status & Audit Classification Taxonomy

To ensure strict compliance with ISO/IEC 17025 Clause 8.4 (*Control of records and documents*), all documentation within CWP-001 is classified into five auditable statuses:

* 🟢 **CURRENT CONTROLLED DOCUMENT**: An active, approved procedure, form, or register in AzureSky's live QMS.
* 🟡 **REFERENCE / EXTERNAL DOCUMENT**: An authentic international standard, statutory regulation, or accredited calibration certificate.
* 🔵 **CWP-001 WORKING DOCUMENT**: A verified engineering analysis, gap matrix, or technical specification developed within this project repository.
* 🔴 **OBSOLETE — HISTORICAL ONLY**: A superseded revision or archived procedure retained strictly for change history; not cited for current authority.
* ⚪ **REQUIRED EXTENSION / TO BE DEVELOPED**: A missing validation dossier, uncertainty model, or SOP identified as necessary for SANAS accreditation.
